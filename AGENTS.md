# Repository rules

## Verification

- Do not run tests or builds for copy, spacing, color, or other small styling changes.
- Batch related edits before verification.
- For behavior changes, run only the most relevant check once after implementation.
- Run the full suite only when explicitly requested or before merging a PR.
- Report concise results. Save verbose output to a temporary log.
- Repeat checks only after a relevant code change or to diagnose a failure.
